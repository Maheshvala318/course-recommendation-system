## 🏗️ Project Overview

A **Streamlit-based Course Recommendation System** that recommends Udemy courses using three ML approaches:
1. **Cosine Similarity** — TF-IDF text features + numeric features hybrid similarity matrix
2. **KNN (K-Nearest Neighbors)** — Combined feature vector with cosine distance
3. **Correlation-based** — On-the-fly cosine similarity on z-scored (standardized) combined features

Also supports **free-text search** via TF-IDF when a title isn't in the dataset.

**Data Source:** ~39MB Udemy dataset (scraped via Scrapy spiders) + Coursera CSV for supplementary data.

## 💡 Coding Conventions

### Python
- **Style:** PEP 8, snake_case for functions/variables, PascalCase for classes
- **Type hints:** Use for function signatures (`def func(x: str) -> list:`)
- **Docstrings:** Google-style docstrings for all public functions
- **Imports:** Group by stdlib → third-party → local, separated by blank lines

### Data Pipeline
- Raw data → `data/raw/` (never modified)
- Processed artifacts → `data/processed/` (pkl files, generated by notebooks)
- Config paths → `src/config/settings.py` (single source of truth)

### Model Artifacts
- All `.pkl` files are **generated** by notebooks, not hand-coded
- The `similarity_matrix.pkl` is ~1.9GB — **must be gitignored**
- Use lazy loading / caching (`@st.cache_data` / `@st.cache_resource`) in production

## ⚠️ Known Issues & Gotchas

1. **Duplicate code in `Model/main3.py`**: Lines 230–459 are an exact duplicate of lines 1–229
2. **Hardcoded MySQL password** in `product_link.py` (`Lost@123`) — must use env vars
3. **~1.9GB similarity matrix** duplicated in root AND `Model/` dir — storage bloat
4. **No `.gitignore`** — large pkl/csv files get committed to git
5. **No caching** — `similarity_matrix.pkl` loaded on every Streamlit rerun
6. **Scrapy spiders reference `books.toscrape.com`** as dummy domain — confusing but functional
